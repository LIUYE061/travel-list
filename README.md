# 出行清单 · Travel List

出差 / 旅游 / 回家 / 露营前，再也不用凭记忆想"我是不是漏了什么"。
选好目的和天数，自动生成分类打包清单，逐项勾选，顶部实时显示打包进度。

**在线体验（GitHub Pages，点开即用，无需安装）：**
👉 https://LIUYE061.github.io/travel-list/

> 同一份页面的中文文件名入口：https://LIUYE061.github.io/travel-list/%E5%87%BA%E8%A1%8C%E6%B8%85%E5%8D%95MVP.html

## 这是什么

一个**单文件、零依赖**的 MVP 网页，用来验证"减少漏带焦虑"这个假设值不值得做下去。
没有账号、没有后端、没有埋点 —— 数据全在你自己浏览器的 localStorage 里。

手机 / 电脑直接打开链接即可使用。建议用链接访问而不是下载后双击打开 `file://`：
`file://` 下个别浏览器（Safari、部分国产浏览器内核）会禁用 localStorage，页面底部会如实提示。

## 已实现

- **5 类出行场景**：出差 / 旅游 / 回家 / 露营 / 短途出行
- **天数换算**：数量随天数自动变化（5 天 → 换洗衣物 ×3、内衣裤 ×5）；不过夜不出现在泳衣、电脑电源线这类条目
- **六大分类清单**：证件 / 电子 / 衣物 / 洗漱 / 药品 / 其他
- **逐项勾选** + 分类级"全部勾上 / 全部取消"
- **打包进度**：吸顶栏百分比 + 进度条 + "还剩 X 件"，100% 时提示出发前复核
- **增删物品**：自定义项带标记；删除后 5 秒内可撤销，连删可逐件撤销
- **本地持久化**：刷新、关页面不丢数据，重开直接回到上次的清单
- **个人模板**：把调好的物品集存给某个场景，下次选同场景自动套用（只记物品、数量按天数重算）

刻意不做的功能（出行方式、返程检查、AI 生成清单、云同步、分享…）见 `减法思维-出行清单.md`。

## 技术要点

- 纯 HTML + CSS + 原生 JS，单文件，无任何外部请求与构建步骤
- localStorage key：`eatwhat.travel-list.v2`；首次打开会自动从旧的 `v1` 迁移一次并提示
- 物品名支持 `{c}` / `{u}` 占位符（如 `内衣裤 ×{u}`），生成时按本次天数解析 —— 这是"模板只记物品、数量随天数重算"的实现基础
- 自定义物品按字面文本渲染，不做占位符替换；所有用户输入走文本节点，不拼接进 HTML

## 数据与隐私

所有数据只存在你本机浏览器里，站点不收集、不上传任何东西。
换设备、换浏览器、或从 `file://` 换成 `http://` 访问，数据都不互通（MVP 不做同步，属预期）。
想清空：清单页「删除清单」（模板保留），或「清除模板」，或控制台执行
`localStorage.removeItem('eatwhat.travel-list.v2')`。
